\section{Résultats de l'étude statistique}

Nous avons comparé les performances des cinq algorithmes implémentés pour résoudre le problème du voyageur de commerce : PPP, OptPPP, OptPrim, OptOptPrim et HDS. L'étude porte sur le temps d'exécution et la qualité des solutions (longueur du cycle).

\subsection{Complexité théorique}

L'analyse des algorithmes nous permet d'établir les ordres de grandeur suivants pour un graphe de $n$ sommets :

\begin{itemize}
    \item \textbf{PPP (Point le Plus Proche)} : $O(n^3)$. L'insertion itérative demande de parcourir l'ensemble des points restants à chaque étape.
    \item \textbf{OptPPP} : Complexité de PPP augmentée par la phase de décroisement (recherche locale).
    \item \textbf{OptPrim} : $O(n^2 \log n)$. L'algorithme de Prim est implémenté avec un tas binaire. Sur un graphe complet ($m \approx n^2$ arêtes), le coût des mises à jour des priorités dans le tas domine, donnant une complexité de $O(m \log n)$ soit $O(n^2 \log n)$.
    \item \textbf{OptOptPrim} : Complexité d'OptPrim augmentée par la phase de décroisement.
    \item \textbf{HDS (Heuristique Déterministe Séquentielle)} : Algorithme de type \textit{Branch and Bound}. Sa complexité est exponentielle dans le pire des cas, car il explore l'arbre des solutions possibles pour trouver l'optimum exact.
\end{itemize}

\subsection{Analyse des performances}

\textbf{Vitesse d'exécution :}
\begin{itemize}
    \item \textbf{OptPrim} se distingue comme l'algorithme le plus rapide, cohérent avec sa complexité théorique plus faible.
    \item \textbf{PPP} est sensiblement plus lent que l'approche basée sur Prim.
    \item L'ajout de l'étape de \textbf{décroisement} (dans OptPPP et OptOptPrim) augmente naturellement le temps de calcul par rapport aux versions de base, mais permet d'affiner la solution.
    \item \textbf{HDS} est extrêmement coûteux en temps dès que le nombre de sommets augmente, le limitant aux petites instances, contrairement aux autres heuristiques qui passent à l'échelle.
\end{itemize}

\textbf{Qualité des solutions :}
\begin{itemize}
    \item \textbf{HDS} fournit toujours la solution optimale (le cycle le plus court possible), servant de référence absolue.
    \item Parmi les heuristiques constructives pures, \textbf{PPP} tend à donner de meilleurs résultats initiaux que \textbf{OptPrim}.
    \item L'application du \textbf{décroisement} est cruciale : elle améliore considérablement la qualité des solutions. \textbf{OptOptPrim} et \textbf{OptPPP} produisent des cycles de longueurs comparables et très compétitifs.
\end{itemize}

\textbf{Conclusion :}
L'algorithme \textbf{OptOptPrim} présente souvent le meilleur compromis global : il bénéficie de la rapidité de construction de l'arbre de Prim et de l'efficacité du décroisement pour produire d'excellentes solutions en un temps très court. HDS reste l'outil de choix uniquement lorsque l'exactitude prime sur le temps de calcul pour de petits graphes.

\section{Algorithme}

\subsection{Point le Plus Proche (PPP)}

\begin{tcolorbox}[colback=darkWhite!75!white,colframe=black!30,left=5pt,right=5pt,top=5pt,bottom=5pt]
\textbf{Algorithme : Procédure PPP (Point le Plus Proche)} \\
\textbf{Description :} Construit un cycle hamiltonien en insérant itérativement le point le plus proche du cycle actuel. \\
\textbf{Vars :}
\begin{itemize}
    \item $c$ : Liste d'entiers (Cycle hamiltonien)
    \item $l$ : Réel (Longueur du cycle)
    \item $Q_i, Q_j$ : Entiers (Indices des points sélectionnés)
\end{itemize}
\textbf{Entrées :}
\begin{itemize}
    \item $L$ : Liste de points $P_1, \dots, P_n$ 
    \item $Q$ : Un point de départ choisi dans $L$
    \item $D$ : La matrice des distances $n \times n$
\end{itemize}
\textbf{Sorties :}
\begin{itemize}
    \item $c$ : Un cycle hamiltonien
    \item $l$ : La longueur du cycle
\end{itemize}
\textbf{Début :}
\begin{enumerate}
    \item $c \leftarrow$ cycle trivial composé du seul point $Q$ \textit{// Initialisation du cycle}
    \item $l \leftarrow 0$
    \item Retirer $Q$ de $L$
    \item Tant que $L$ n'est pas vide faire : \textit{// Boucle principale d'insertion}
    \item \quad $(Q_i, Q_j) \leftarrow \texttt{TrouverCoupleMin}(L, c, D)$ \textit{// Trouver le couple minimisant la distance}
    \item \quad $(c, l) \leftarrow \texttt{InsérerDansCycle}(c, Q_i, Q_j, D, l)$ \textit{// Insérer et mettre à jour}
    \item \quad Retirer $Q_i$ de $L$
    \item Retourner $c, l$
\end{enumerate}
\end{tcolorbox}

\vspace{5mm}

\begin{tcolorbox}[colback=darkWhite!75!white,colframe=black!30,left=5pt,right=5pt,top=5pt,bottom=5pt]
\textbf{Algorithme : InsérerDansCycle} \\
\textbf{Description :} Insère $Q_i$ dans $c$ soit entre $Q_j$ et son successeur, soit entre son prédécesseur et $Q_j$, selon le coût minimal, et met à jour la longueur du cycle. \\
\textbf{Vars :}
\begin{itemize}
    \item $Q_{next}, Q_{prev}$ : Entiers (Indices des voisins de $Q_j$)
    \item $\text{coût}_{\text{droite}}, \text{coût}_{\text{gauche}}$ : Réels (Coûts d'insertion)
\end{itemize}
\textbf{Entrées :}
\begin{itemize}
    \item $c$ : Cycle partiel
    \item $Q_i$ : Point à insérer
    \item $Q_j$ : Point d'ancrage dans $c$
    \item $D$ : Matrice des distances
    \item $l$ : Longueur actuelle du cycle
\end{itemize}
\textbf{Sorties :} $c$ (cycle mis à jour), $l$ (nouvelle longueur) \\
\textbf{Début :}
\begin{enumerate}
    \item Soit $Q_{next}$ le successeur de $Q_j$ dans $c$
    \item Soit $Q_{prev}$ le prédécesseur de $Q_j$ dans $c$
    \item $\text{coût}_{\text{droite}} \leftarrow D[Q_j, Q_i] + D[Q_i, Q_{next}] - D[Q_j, Q_{next}]$ \textit{// Coût insertion droite}
    \item $\text{coût}_{\text{gauche}} \leftarrow D[Q_{prev}, Q_i] + D[Q_i, Q_j] - D[Q_{prev}, Q_j]$ \textit{// Coût insertion gauche}
    \item Si $\text{coût}_{\text{droite}} \leq \text{coût}_{\text{gauche}}$ alors : \textit{// Choix du meilleur coût}
    \item \quad Insérer $Q_i$ entre $Q_j$ et $Q_{next}$ dans $c$
    \item \quad $l \leftarrow l + \text{coût}_{\text{droite}}$
    \item Sinon :
    \item \quad Insérer $Q_i$ entre $Q_{prev}$ et $Q_j$ dans $c$
    \item \quad $l \leftarrow l + \text{coût}_{\text{gauche}}$
    \item Retourner $c, l$
\end{enumerate}
\end{tcolorbox}


\begin{tcolorbox}[colback=darkWhite!75!white,colframe=black!30,left=5pt,right=5pt,top=5pt,bottom=5pt]
\textbf{Algorithme : TrouverCoupleMin} \\
\textbf{Description :} Trouve le couple $(Q_i, Q_j)$ tel que $Q_i \in L$, $Q_j \in c$ et la distance $D[Q_i, Q_j]$ est minimale. \\
\textbf{Vars :}
\begin{itemize}
    \item $d_{min}$ : Réel (Distance minimale trouvée)
    \item $u, v$ : Entiers (Indices de parcours)
\end{itemize}
\textbf{Entrées :}
\begin{itemize}
    \item $L$ : Liste des points non encore visités
    \item $c$ : Le cycle partiel actuel
    \item $D$ : La matrice des distances $n \times n$
\end{itemize}
\textbf{Sorties :} $Q_i$ (point sélectionné dans $L$), $Q_j$ (point d'ancrage dans $c$) \\
\textbf{Début :}
\begin{enumerate}
    \item $d_{min} \leftarrow \infty$
    \item $Q_i \leftarrow \text{vide}$
    \item $Q_j \leftarrow \text{vide}$
    \item Pour chaque point $u$ appartenant à $L$ faire : \textit{// Parcourir les points non visités}
    \item \quad Pour chaque point $v$ appartenant à $c$ faire : \textit{// Parcourir les points du cycle}
    \item \quad \quad Si $D[u, v] < d_{min}$ alors : \textit{// Vérifier si distance minimale}
    \item \quad \quad \quad $d_{min} \leftarrow D[u, v]$
    \item \quad \quad \quad $Q_i \leftarrow u$
    \item \quad \quad \quad $Q_j \leftarrow v$
    \item Retourner $Q_i, Q_j$
\end{enumerate}
\end{tcolorbox}

\textbf{Implémentation Python :}
\begin{lstlisting}[language=Python, caption=Implémentation de PPP]
def trouver_couple_min(L, c, D):
    """
    Trouve le couple (Q_i, Q_j) tel que Q_i dans L, Q_j dans c et D[Q_i, Q_j] est minimale.
    Args:
        L (list): Liste des indices des points non encore visités
        c (list): Liste des indices du cycle partiel actuel
        D (np.ndarray): Matrice des distances n x n
    Returns:
        tuple: (Q_i, Q_j) indices
    """
    # Initialisation des variables pour suivre la distance minimale et les indices correspondants
    d_min = float('inf')
    Q_i = None
    Q_j = None
    # Parcourir tous les couples (u, v) avec u dans L et v dans c
    for u in L:
        for v in c:
            # Vérifier si la distance D[u, v] est inférieure à la distance minimale actuelle
            if D[u, v] < d_min:
                # Mettre à jour la distance minimale et les indices correspondants
                d_min = D[u, v]
                Q_i = u
                Q_j = v

    return Q_i, Q_j

def inserer_dans_cycle(c, Q_i, Q_j, D, l):
    """
    Insère Q_i dans c entre Q_j et son point adjacent, met à jour la longueur du cycle.
    Args:
        c (list): Liste des indices du cycle partiel
        Q_i (int): Indice du point à insérer
        Q_j (int): Indice du point d'ancrage dans c
        D (np.ndarray): Matrice des distances
        l (float): Longueur actuelle du cycle
    Returns:
        tuple: (c, l) cycle mis à jour et nouvelle longueur
    """
    # Taille du cycle
    n = len(c)
    # Index de Q_j dans le cycle
    idx_j = c.index(Q_j)

    # Insertion entre Q_j et le suivant (j+1)
    idx_next = (idx_j + 1) % n
    Q_next = c[idx_next]
    cout_droite = D[Q_j, Q_i] + D[Q_i, Q_next] - D[Q_j, Q_next]

    # Insertion entre le précédent (j-1) et Q_j
    idx_prev = (idx_j - 1) % n
    Q_prev = c[idx_prev]
    cout_gauche = D[Q_prev, Q_i] + D[Q_i, Q_j] - D[Q_prev, Q_j]

    # Choix du meilleur cout d'insertion
    if cout_droite <= cout_gauche:
        c.insert(idx_j + 1, Q_i)
        l += cout_droite
    else:
        c.insert(idx_j, Q_i)
        l += cout_gauche

    return c, l

def ppp(D, Q=0):
    """
    Procédure PPP : construit un cycle hamiltonien en insérant itérativement le point le plus proche du cycle actuel.
    Args:
        D (np.ndarray): Matrice des distances.
        Q (int, optional): Indice du point de départ. Si None, prend 0.
    Returns:
        tuple: (c, l) cycle hamiltonien (liste d'indices), longueur du cycle
    """
    # taille du graphe
    n = len(D)
    if n == 0:
        return [], 0.0
    # Liste des points non encore visités
    L = list(range(n))
    # Initialisation du cycle avec le point de départ Q
    c = [Q]
    # Longueur initiale du cycle
    l = 0.0
    # Retirer Q de la liste des points non visités
    L.remove(Q)

    # Boucle principale d'insertion tant qu'il reste des points à insérer
    while L != []:
        # trouver le couple (Q_i, Q_j) minimisant la distance
        Q_i, Q_j = trouver_couple_min(L, c, D)
        # insérer Q_i dans le cycle c et mettre à jour la longueur
        c, l = inserer_dans_cycle(c, Q_i, Q_j, D, l)
        # retirer Q_i de L
        L.remove(Q_i)

    return c, l
\end{lstlisting}

\subsection{Point le Plus Proche Optimisé (OptPPP)}

\begin{tcolorbox}[colback=darkWhite!75!white,colframe=black!30,left=5pt,right=5pt,top=5pt,bottom=5pt]
\textbf{Algorithme : Procédure Décroise} \\
\textbf{Description :} Améliore un cycle en décroisant les arêtes tant que cela réduit la distance totale. \\
\textbf{Vars :}
\begin{itemize}
    \item $n$ : Entier (Nombre de points)
    \item $\text{amélioration}$ : Booléen (Indicateur de modification)
    \item $i, j$ : Entiers (Indices de boucle)
    \item $u, v, x, y$ : Entiers (Indices des points des arêtes)
    \item $d_{actuelle}, d_{nouvelle}$ : Réels (Distances comparées)
    \item $p, q$ : Entiers (Indices pour l'inversion)
\end{itemize}
\textbf{Entrées :}
\begin{itemize}
    \item $c$ : Cycle hamiltonien initial
    \item $D$ : Matrice des distances
\end{itemize}
\textbf{Sorties :} $c$ (cycle optimisé), $l$ (longueur) \\
\textbf{Début :}
\begin{enumerate}
    \item $n \leftarrow \text{taille}(c)$
    \item $\text{amélioration} \leftarrow \text{Vrai}$
    \item Tant que $\text{amélioration}$ faire : \textit{// Boucle jusqu'à stabilité}
    \item \quad $\text{amélioration} \leftarrow \text{Faux}$
    \item \quad Pour $i$ allant de $1$ à $n-2$ faire : \textit{// Parcourir les paires d'arêtes}
    \item \quad \quad Pour $j$ allant de $i+2$ à $n$ faire :
    \item \quad \quad \quad $u \leftarrow c[i]$
    \item \quad \quad \quad $v \leftarrow c[i+1]$
    \item \quad \quad \quad $x \leftarrow c[j]$
    \item \quad \quad \quad Si $j = n$ alors :
    \item \quad \quad \quad \quad $y \leftarrow c[1]$
    \item \quad \quad \quad Sinon :
    \item \quad \quad \quad \quad $y \leftarrow c[j+1]$
    \item \quad \quad \quad $d_{actuelle} \leftarrow D[u, v] + D[x, y]$
    \item \quad \quad \quad $d_{nouvelle} \leftarrow D[u, x] + D[v, y]$
    \item \quad \quad \quad Si $d_{nouvelle} < d_{actuelle}$ alors : \textit{// Si amélioration trouvée}
    \item \quad \quad \quad \quad $c[i+1 \dots j] \leftarrow \text{inverser}(c[i+1 \dots j])$ \textit{// Inversion sous-séquence}
    \item \quad \quad \quad \quad $\text{amélioration} \leftarrow \text{Vrai}$
    \item $l \leftarrow \text{CalculerLongueur}(c, D)$ \textit{// Recalcul longueur}
    \item Retourner $c, l$
\end{enumerate}
\end{tcolorbox}

\vspace{5mm}

\begin{tcolorbox}[colback=darkWhite!75!white,colframe=black!30,left=5pt,right=5pt,top=5pt,bottom=5pt]
\textbf{Algorithme : Procédure OptPPP} \\
\textbf{Description :} Wrapper pour l'algorithme de décroisement. \\
\textbf{Vars :} Aucune \\
\textbf{Entrées :}
\begin{itemize}
    \item $c$ : Cycle hamiltonien initial
    \item $D$ : Matrice des distances
\end{itemize}
\textbf{Sorties :} $c$ (cycle optimisé), $l$ (longueur) \\
\textbf{Début :}
\begin{enumerate}
    \item Retourner $\texttt{Décroise}(c, D)$
\end{enumerate}
\end{tcolorbox}

\textbf{Implémentation Python :}
\begin{lstlisting}[language=Python, caption=Implémentation de OptPPP]
def decroise(c, D):
    """
    Améliore le cycle en décroisant les arêtes.
    Args:
        c (list): Cycle hamiltonien (liste d'indices)
        D (np.ndarray): Matrice des distances
    Returns:
        tuple: (c, l) cycle optimisé et sa nouvelle longueur
    """
    # taille du cycle
    n = len(c)
    amelioration = True
    # Boucle jusqu'à ce qu'il n'y ait plus d'amélioration
    while amelioration:
        amelioration = False
        # Parcourir toutes les paires d'arêtes non adjacentes
        for i in range(n - 2):
            # j doit être au moins i+2 pour éviter les arêtes adjacentes
            for j in range(i + 2, n):
                # u et v sont les extrémités de la première arête
                u = c[i]
                v = c[i + 1]
                # x et y sont les extrémités de la deuxième arête
                x = c[j]
                y = c[(j + 1) % n]
                # calcul des distances actuelles et nouvelles
                d_act = D[u, v] + D[x, y]
                d_nouv = D[u, x] + D[v, y]
                # Si le décroisement améliore la longueur du cycle
                if d_nouv < d_act:
                    # Inversion de la sous-séquence entre i+1 et j
                    c[i+1:j+1] = c[i+1:j+1][::-1]
                    amelioration = True

    # Recalcul de la longueur totale du cycle optimisé
    l = 0.0
    for k in range(n):
        l += D[c[k], c[(k + 1) % n]]

    return c, l

def optppp(D, r0=0):
    """
    Procédure OptPPP : améliore le cycle fourni par PPP en décroisant les arêtes.
    Args:
        D (np.ndarray): Matrice des distances
        r0 (int, optional): Sommet de départ. Par défaut 0.
    Returns:
        tuple: (c, l) cycle optimisé et sa nouvelle longueur
    """
    # Obtenir le cycle initial via PPP
    c, _ = ppp(D, r0)
    # Décroisement
    return decroise(c, D)
\end{lstlisting}

\subsection{Parcours préfixe d'un ACM à partir de Prim (OptPrim)}


\begin{tcolorbox}[colback=darkWhite!75!white,colframe=black!30,left=5pt,right=5pt,top=5pt,bottom=5pt]
\textbf{Structure de données : GraphePrim}

\textbf{Type} GraphePrim = \textbf{Enregistrement} \\
\quad cle : Tableau[1..n] de Réel; \\
\quad pred : Tableau[1..n] d'Entier; \\
\quad NoeudTas : Tableau[1..n] d'Entier \\
\quad Tas : Tableau[1..n] d'Entier \\
\textbf{Fin};
\end{tcolorbox}


\begin{tcolorbox}[colback=darkWhite!75!white,colframe=black!30,left=5pt,right=5pt,top=5pt,bottom=5pt]
\textbf{Algorithme : Prim (Optimisé)} \\
\textbf{Description :} Construit un arbre couvrant de poids minimum (MST) en utilisant un tas binaire pour sélectionner efficacement le prochain sommet le plus proche. \\
\textbf{Vars :}
\begin{itemize}
    \item $GraphePrim$ : Structure GraphePrim (Données du graphe et du tas)
    \item $pres$ : Tableau de booléens (Indique si un sommet est dans le tas)
    \item $u, v$ : Entiers (Indices de sommets)
\end{itemize}
\textbf{Entrées :}
\begin{itemize}
    \item $D$ : Matrice des distances $n \times n$
    \item $r0$ : Sommet de départ (par défaut 1)
\end{itemize}
\textbf{Sorties :}
\begin{itemize}
    \item $pred$ : Liste des prédécesseurs définissant l'arbre couvrant
\end{itemize}
\textbf{Début :}
\begin{enumerate}
    \item Initialiser $GraphePrim$ avec $n$ sommets
    \item $pres \leftarrow$ Tableau de booléens initialisé à \texttt{Vrai} (indique si un sommet est dans le tas)
    \item $GraphePrim.cle[r0] \leftarrow 0$ \textit{// Initialiser clé départ}
    \item $GraphePrim.echanger(1, GraphePrim.noeudTas[r0])$ \textit{// Placer r0 à la racine}
    \item Tant que $GraphePrim.tas$ n'est pas vide faire : \textit{// Boucle principale}
    \item \quad $u \leftarrow GraphePrim.tas[1]$ \textit{// Extraire le min}
    \item \quad $pres[u] \leftarrow \texttt{Faux}$ \textit{// Marquer comme visité}
    \item \quad $GraphePrim.echanger(1, \text{taille}(tas))$
    \item \quad Retirer le dernier élément de $GraphePrim.tas$
    \item \quad Si $GraphePrim.tas$ non vide alors :
    \item \quad \quad $GraphePrim.versLeBas(1)$ \textit{// Réajuster le tas}
    \item \quad Pour chaque sommet $v$ de $1$ à $n$ faire : \textit{// Mettre à jour voisins}
    \item \quad \quad Si $pres[v]$ et $D[u, v] < GraphePrim.cle[v]$ alors :
    \item \quad \quad \quad $GraphePrim.cle[v] \leftarrow D[u, v]$
    \item \quad \quad \quad $GraphePrim.pred[v] \leftarrow u$
    \item \quad \quad \quad $GraphePrim.versLeHaut(GraphePrim.noeudTas[v])$ \textit{// Remonter dans le tas}
    \item Retourner $GraphePrim.pred$
\end{enumerate}
\end{tcolorbox}

\vspace{5mm}

\begin{tcolorbox}[colback=darkWhite!75!white,colframe=black!30,left=5pt,right=5pt,top=5pt,bottom=5pt]
\textbf{Algorithme : PredToTree} \\
\textbf{Description :} Convertit la liste des prédécesseurs en une structure d'arbre (dictionnaire d'adjacence). \\
\textbf{Vars :}
\begin{itemize}
    \item $d$ : Dictionnaire (Liste d'adjacence)
    \item $racine$ : Entier (Indice de la racine)
    \item $i$ : Entier (Indice de boucle)
\end{itemize}
\textbf{Entrées :}
\begin{itemize}
    \item $pred$ : Liste des prédécesseurs
\end{itemize}
\textbf{Sorties :} $d$ (arbre), $racine$ \\
\textbf{Début :}
\begin{enumerate}
    \item $d \leftarrow$ Dictionnaire vide
    \item $racine \leftarrow -1$
    \item Pour $i$ allant de $1$ à $\text{taille}(pred)$ faire : \textit{// Initialisation}
    \item \quad $d[i] \leftarrow$ Liste vide
    \item \quad Si $pred[i]$ est \texttt{None} ou $-1$ alors : \textit{// Trouver racine}
    \item \quad \quad $racine \leftarrow i$
    \item Pour $i$ allant de $1$ à $\text{taille}(pred)$ faire : \textit{// Remplir adjacence}
    \item \quad Si $pred[i]$ n'est pas \texttt{None} et $pred[i] \neq -1$ alors :
    \item \quad \quad Ajouter $i$ à $d[pred[i]]$ \textit{// Ajouter enfant}
    \item Retourner $d, racine$
\end{enumerate}
\end{tcolorbox}

\vspace{5mm}

\begin{tcolorbox}[colback=darkWhite!75!white,colframe=black!30,left=5pt,right=5pt,top=5pt,bottom=5pt]
\textbf{Algorithme : ParcoursPrefixe} \\
\textbf{Description :} Effectue un parcours en profondeur (DFS) pour obtenir l'ordre de visite des sommets. \\
\textbf{Vars :}
\begin{itemize}
    \item $stack$ : Pile d'entiers
    \item $p$ : Tableau d'entiers (Marquage visite)
    \item $p\_etoile$ : Liste d'entiers (Résultat)
    \item $count$ : Entier
    \item $lst\_voisin$ : Liste d'entiers
    \item $rep$ : Booléen
    \item $voisin$ : Entier
\end{itemize}
\textbf{Entrées :}
\begin{itemize}
    \item $d$ : Dictionnaire d'adjacence
    \item $racine$ : Entier
\end{itemize}
\textbf{Sorties :} $p\_etoile$ (liste ordonnée) \\
\textbf{Début :}
\begin{enumerate}
    \item $stack \leftarrow [racine]$ \textit{// Initialisation pile}
    \item $p \leftarrow$ Tableau de zéros de taille $n$
    \item $p\_etoile \leftarrow [racine]$
    \item $p[racine] \leftarrow 1$ \textit{// Marquer racine}
    \item $count \leftarrow 2$
    \item Tant que $stack$ n'est pas vide faire : \textit{// Parcours}
    \item \quad $lst\_voisin \leftarrow d[\text{sommet}(stack)]$
    \item \quad $rep \leftarrow \text{Faux}$
    \item \quad Pour chaque $voisin$ dans $lst\_voisin$ faire : \textit{// Parcourir voisins}
    \item \quad \quad Si $p[voisin] == 0$ alors : \textit{// Si non visité}
    \item \quad \quad \quad Empiler $voisin$ sur $stack$
    \item \quad \quad \quad Ajouter $voisin$ à $p\_etoile$
    \item \quad \quad \quad $p[voisin] \leftarrow count$
    \item \quad \quad \quad $count \leftarrow count + 1$
    \item \quad \quad \quad $rep \leftarrow \text{Vrai}$
    \item \quad \quad \quad Sortir de la boucle Pour
    \item \quad Si non $rep$ alors : \textit{// Si aucun voisin non visité}
    \item \quad \quad Dépiler de $stack$
    \item Retourner $p\_etoile$
\end{enumerate}
\end{tcolorbox}

\vspace{5mm}

\begin{tcolorbox}[colback=darkWhite!75!white,colframe=black!30,left=5pt,right=5pt,top=5pt,bottom=5pt]
\textbf{Algorithme : Procédure OptPrim} \\
\textbf{Description :} Construit un cycle hamiltonien à partir de l'arbre couvrant minimal. \\
\textbf{Vars :}
\begin{itemize}
    \item $pred$ : Liste d'entiers
    \item $d$ : Dictionnaire
    \item $racine$ : Entier
    \item $c$ : Liste d'entiers
    \item $l$ : Réel
\end{itemize}
\textbf{Entrées :}
\begin{itemize}
    \item $points$ : Liste de points
    \item $D$ : Matrice des distances
    \item $r0$ : Sommet de départ
\end{itemize}
\textbf{Sorties :} $c, l$ \\
\textbf{Début :}
\begin{enumerate}
    \item Si $D$ est \texttt{None} alors :
    \item \quad $D \leftarrow \texttt{CalculerMatriceDistances}(points)$
    \item $pred \leftarrow \texttt{Prim}(D, r0)$ \textit{// Arbre couvrant minimal}
    \item $(d, racine) \leftarrow \texttt{PredToTree}(pred)$ \textit{// Conversion en arbre}
    \item $c \leftarrow \texttt{ParcoursPrefixe}(d, racine)$ \textit{// Cycle via parcours}
    \item $l \leftarrow \texttt{CalculerLongueur}(c, D)$ \textit{// Calcul longueur}
    \item Retourner $c, l$
\end{enumerate}
\end{tcolorbox}

\textbf{Implémentation Python :}
\begin{lstlisting}[language=Python, caption=Implémentation de OptPrim]
class GraphePrim:
    def __init__(self, n):
        """
        Initialise la structure de données pour l'algorithme de Prim.
        Args:
            n (int): Nombre de sommets du graphe.
        """
        self.cle = [float('inf')] * n
        self.pred = [None] * n
        self.noeudTas = list(range(n))
        self.tas = list(range(n))
    
    def echanger(self, i, j):
        """
        Échange deux éléments dans le tas et met à jour leurs positions.
        Args:
            i (int): Indice du premier élément dans le tas.
            j (int): Indice du deuxième élément dans le tas.
        """
        temp = self.tas[i]
        self.tas[i] = self.tas[j]
        self.tas[j] = temp
        self.noeudTas[self.tas[i]] = i
        self.noeudTas[self.tas[j]] = j

    def priorite(self, i):
        """
        Retourne la priorité (clé) d'un élément à une position donnée dans le tas.
        Args:
            i (int): Indice dans le tas.
        Returns:
            float: La valeur de la clé associée.
        """
        return self.cle[self.tas[i]]
        
    def versLeHaut(self, i):
        """
        Fait remonter un élément dans le tas pour respecter la propriété de tas min.
        Args:
            i (int): Indice de l'élément à faire remonter.
        """
        # Remonter tant que l'élément a une priorité inférieure à son parent
        while i > 0 and self.priorite(i) < self.priorite((i - 1) // 2):
            # Échanger avec le parent
            self.echanger(i, (i - 1) // 2)
            # Mettre à jour l'indice pour continuer à remonter
            i = (i - 1) // 2

    def versLeBas(self, i):
        """
        Fait descendre un élément dans le tas pour respecter la propriété de tas min.
        Args:
            i (int): Indice de l'élément à faire descendre.
        """
        # Indice du fils gauche
        s = 2 * i + 1
        # Descendre tant que l'élément a une priorité supérieure à l'un de ses enfants
        while s < len(self.tas):
            # Trouver l'enfant avec la plus petite priorité en comparant les deux fils et si c'est le droit
            if s + 1 < len(self.tas) and self.priorite(s + 1) < self.priorite(s):
                # Prendre le fils droit
                s += 1
            # Si l'élément courant a une priorité supérieure à son enfant
            if self.priorite(i) > self.priorite(s):
                # echanger et continuer à descendre
                self.echanger(i, s)
                # Mettre à jour l'indice courant de l'elément à descendre
                i = s
                # Mettre à jour l'indice avec le fils gauche
                s = 2 * i + 1
            # Sinon, la propriété de tas est respectée
            else:
                break

def prim(D, r0=0):
    """
    Algorithme de Prim pour trouver l'arbre couvrant de poids minimal.
    Args:
        D (np.ndarray): Matrice des distances
        r0 (int, optional): Sommet de départ. Par défaut 0.
    Returns:
        list: Liste des prédécesseurs (pred[i] est le parent de i dans l'arbre)
    """
    n = len(D)
    graphe = GraphePrim(n)
    pres = [True] * n

    # Initialiser la clé du sommet de départ
    graphe.cle[r0] = 0
    # Placer r0 à la racine du tas
    graphe.echanger(0, graphe.noeudTas[r0])

    # Boucle principale de Prim
    while len(graphe.tas) > 0:
        # Extraire le sommet u de clé minimale
        u = graphe.tas[0]
        # Marquer u comme inclus dans l'arbre
        pres[u] = False
        
        # Retirer u du tas
        graphe.echanger(0, len(graphe.tas) - 1)
        graphe.tas.pop()
        
        # Reajuster le tas
        if len(graphe.tas) > 0:
            graphe.versLeBas(0)

        # Mettre à jour les clés et prédécesseurs des sommets adjacents
        for v in range(n):
            # Si v est encore dans le tas et l'arête (u, v) est plus petite que la clé actuelle
            if pres[v] and D[u, v] < graphe.cle[v]:
                # Mettre à jour la clé et le prédécesseur
                graphe.cle[v] = D[u, v]
                graphe.pred[v] = u
                # Faire remonter v dans le tas
                graphe.versLeHaut(graphe.noeudTas[v])
        
    return graphe.pred

def pred_to_tree(pred):
    """
    Convertit la liste des prédécesseurs en une structure d'arbre (dictionnaire d'adjacence).
    Args:
        pred (list): Liste des prédécesseurs où pred[i] est le parent de i.
    Returns:
        tuple: (d, racine) où d est le dictionnaire d'adjacence et racine est l'indice de la racine.
    """
    d = {}
    racine = -1
    # Initialisation du dictionnaire d'adjacence
    for i in range(len(pred)):
        # Chaque nœud a une liste vide au départ
        d[i] = []
        # Trouver la racine
        if pred[i] is None or pred[i] == -1:
            racine = i

    # Remplir le dictionnaire d'adjacence
    for i in range(len(pred)):
        # Ajouter i comme enfant de son prédécesseur
        if pred[i] is not None and pred[i] != -1:
            # Ajouter i à la liste des enfants de pred[i]
            d[pred[i]].append(i)

    return d, racine


def parcours_prefixe(d, racine):
    """
    Effectue un parcours préfixe (DFS) de l'arbre pour obtenir l'ordre de visite des sommets.
    Args:
        d (dict): Dictionnaire d'adjacence de l'arbre.
        racine (int): Indice de la racine de l'arbre.
    Returns:
        list: Liste des sommets dans l'ordre du parcours préfixe.
    """
    # Initialisation de la pile avec la racine
    stack = [racine]
    # Marquage des sommets visités en lui attribuant l'ordre de visite
    p = [0] * len(d)
    # Liste du parcours préfixe
    p_etoile = [racine]
    # Marquer la racine comme visitée
    p[racine] = 1
    count = 2

    # Parcours prefixe
    while len(stack) > 0 :
        # Récupérer le sommet au sommet de la pile
        lst_voisin = d[stack[len(stack) -1]]
        rep = False

        # Parcourir les voisins
        for i in range(len(lst_voisin)):
            # voisin courant de i
            voisin = lst_voisin[i]
            # Si le voisin n'a pas été visité
            if p[voisin] ==0 :
                # L'ajouter à la pile
                stack.append(voisin)
                # L'ajouter au parcours préfixe
                p_etoile.append(voisin)
                # Marquer comme visité en lui attribuant l'ordre de visite
                p[voisin] = count
                count +=1
                # Indiquer qu'on a trouvé un voisin non visité
                rep = True
                break

        # Si aucun voisin non visité n'a été trouvé, dépiler
        if not rep :
            stack.pop()

    return p_etoile

def optPrim(D, r0=0):
    """
    Procédure OptPrim : construit un cycle hamiltonien à partir de l'arbre couvrant minimal en utilisant un parcours préfixe.
    Args:
        D (np.ndarray): Matrice des distances.
        r0 (int, optional): Sommet de départ pour Prim. Par défaut 0.
    Returns:
        tuple: (c, l) cycle hamiltonien (liste d'indices), longueur du cycle
    """
    # Obtenir l'arbre couvrant minimal via Prim
    pred = prim(D, r0)
    # Convertir les prédécesseurs en arbre
    d, racine = pred_to_tree(pred)
    # Obtenir le cycle via un parcours préfixe de l'arbre
    c = parcours_prefixe(d, racine)

    # Calcul de la longueur totale du cycle
    l = 0.0
    n = len(c)
    for k in range(n):
        l += D[c[k], c[(k + 1) % n]]

    return c, l

\end{lstlisting}

\subsection{OptPrim + Décroisé (OptOptPrim)}

\begin{tcolorbox}[colback=darkWhite!75!white,colframe=black!30,left=5pt,right=5pt,top=5pt,bottom=5pt]
\textbf{Algorithme : Procédure OptOptPrim} \\
\textbf{Description :} Combine OptPrim et le décroisement. \\
\textbf{Vars :}
\begin{itemize}

\end{itemize}
\textbf{Entrées :}

    \item $D$ : Matrice des distances
    \item $r0$ : Sommet de départ
\end{itemize}
\textbf{Sorties :} $c, l$ \\

    \item \quad $D \leftarrow \texttt{CalculerMatriceDistances}(points)$

\end{tcolorbox}

def optOptPrim(D, r0=0):

    Procédure OptOptPrim : combine OptPrim (MST + DFS) et décroisement.

\subsection{Évaluation et séparation progressive ("branch and bound") (HDS)}

\begin{tcolorbox}[colback=darkWhite!75!white,colframe=black!30,left=5pt,right=5pt,top=5pt,bottom=5pt]
\textbf{Structure de données : Noeud}

\textbf{Type} Noeud = \textbf{Enregistrement} \\
\quad chemin : Liste d'Entiers; \\
\quad cout\_actuel : Réel; \\
\quad dernier : Entier; \\
\quad borne : Réel \\
\textbf{Fin};
\end{tcolorbox}

\begin{tcolorbox}[colback=darkWhite!75!white,colframe=black!30,left=5pt,right=5pt,top=5pt,bottom=5pt]
\textbf{Structure de données : Tas}

\textbf{Type} Tas = \textbf{Enregistrement} \\
\quad tas : Liste de Noeuds \\
\textbf{Fin};
\end{tcolorbox}

\vspace{5mm}

\begin{tcolorbox}[colback=darkWhite!75!white,colframe=black!30,left=5pt,right=5pt,top=5pt,bottom=5pt]
\textbf{Algorithme : CalcBorne} \\
\textbf{Description :} Calcule une borne inférieure du coût total pour un nœud donné. \\
\textbf{Vars :}
\begin{itemize}
    \item $somme$ : Réel
    \item $debut, fin$ : Entiers (Extrémités du chemin partiel)
\end{itemize}
\textbf{Entrées :}
\begin{itemize}
    \item $noeud$ : Structure Noeud
    \item $D$ : Matrice des distances
\end{itemize}
\textbf{Sorties :} $borne$ (Réel) \\
\textbf{Début :}
\begin{enumerate}
    \item $somme \leftarrow 0$
    \item $debut \leftarrow noeud.chemin[1]$
    \item $fin \leftarrow noeud.chemin[\text{dernier}]$
    \item Pour chaque sommet $i$ du graphe faire :
    \item \quad Si $i$ est interne au chemin alors : \textit{// Cas 1 : Sommet interne}
    \item \quad \quad Ajouter à $somme$ les distances vers ses deux voisins dans le chemin
    \item \quad Sinon si $i$ est une extrémité ($debut$ ou $fin$) alors : \textit{// Cas 2 : Extrémité}
    \item \quad \quad Ajouter à $somme$ la distance vers son voisin dans le chemin
    \item \quad \quad Ajouter à $somme$ la distance minimale vers un sommet non connecté à $i$ dans le chemin
    \item \quad Sinon ($i$ hors du chemin) : \textit{// Cas 3 : Hors chemin}
    \item \quad \quad Ajouter à $somme$ les deux plus petites distances incidentes à $i$
    \item Retourner $somme / 2$
\end{enumerate}
\end{tcolorbox}

\vspace{5mm}

\begin{tcolorbox}[colback=darkWhite!75!white,colframe=black!30,left=5pt,right=5pt,top=5pt,bottom=5pt]
\textbf{Algorithme : HDS (Branch and Bound)} \\
\textbf{Description :} Recherche le cycle hamiltonien de coût minimal en explorant l'espace des solutions à l'aide d'un arbre de recherche et d'une fonction d'évaluation (borne). \\
\textbf{Vars :}
\begin{itemize}
    \item $tas$ : Structure Tas
    \item $noeud\_courant, nouveau\_noeud$ : Structure Noeud
    \item $c$ : Liste d'entiers (Meilleur cycle)
    \item $l$ : Réel (Meilleur coût)
    \item $cout\_total$ : Réel
\end{itemize}
\textbf{Entrées :}
\begin{itemize}
    \item $D$ : Matrice des distances
\end{itemize}
\textbf{Sorties :} $c, l$ \\
\textbf{Début :}
\begin{enumerate}
    \item $c \leftarrow []$, $l \leftarrow \infty$
    \item $tas \leftarrow \text{NouveauTas}()$
    \item $tas.\text{insere}(\text{NouveauNoeud}([0], 0, D))$ \textit{// Initialisation avec racine}
    \item Tant que $tas$ n'est pas vide faire :
    \item \quad $noeud\_courant \leftarrow tas.\text{extraire\_min}()$ \textit{// Extraire min borne}
    \item \quad Si $noeud\_courant.borne \geq l$ alors : \textit{// Élagage}
    \item \quad \quad Continuer (élagage)
    \item \quad Si $\text{taille}(noeud\_courant.chemin) == n$ alors : \textit{// Chemin complet}
    \item \quad \quad $cout\_total \leftarrow noeud\_courant.cout\_actuel + D[noeud\_courant.dernier, noeud\_courant.chemin[1]]$
    \item \quad \quad Si $cout\_total < l$ alors : \textit{// Meilleure solution ?}
    \item \quad \quad \quad $l \leftarrow cout\_total$
    \item \quad \quad \quad $c \leftarrow noeud\_courant.chemin + [noeud\_courant.chemin[1]]$
    \item \quad Sinon : \textit{// Brancher}
    \item \quad \quad Pour chaque sommet $i$ non dans $noeud\_courant.chemin$ faire :
    \item \quad \quad \quad Créer $nouveau\_noeud$ en ajoutant $i$ au chemin
    \item \quad \quad \quad $tas.\text{insere}(nouveau\_noeud)$ \textit{// Insérer successeur}
    \item Retourner $c, l$
\end{enumerate}
\end{tcolorbox}

\begin{lstlisting}[language=Python, caption=Implémentation de HDS]
class Noeud:
    def __init__(self, chemin, cout_actuel, D):
        self.chemin = chemin
        self.cout_actuel = cout_actuel
        self.dernier = chemin[-1]

        self.borne = self.calc_borne(D)

    def calc_borne(self, D):
        """
        Calcule une borne inférieure du coût total pour le noeud courant. (demi somme)
        Args:
            D (np.ndarray): Matrice des distances
        Returns:
            float: Borne inférieure du coût total (demi somme)
        """
        n = len(D)
        some = 0.0
        debut = self.chemin[0]
        fin = self.chemin[-1]

        for i in range(n):
            # Cas 1 : Le sommet est déja completement dans le chemin : A->B->i->C->D
            if i in self.chemin and not i == debut and not i == fin:
                idx = self.chemin.index(i)
                # prendre les deux points adjacents dans le chemin
                some += D[self.chemin[idx - 1], i] + D[i, self.chemin[idx + 1]]

            # Cas 2 : Une extrémité du chemin n'est pas dans le chemin : i->B->C->D ou A->B->C->i
            elif (i == debut or i == fin) and len(self.chemin) > 1:
                # prendre le point adjacent qui est dans le chemin
                if i == debut:
                    some += D[i, self.chemin[1]]
                else:
                    some += D[self.chemin[-2], i]
                # trouve le minimum parmi les autres
                min_val = float('inf')
                for j in range(n):
                    if min_val > D[i, j] and not i == j:
                        if i == debut and j != self.chemin[1]:
                            min_val = D[i, j]
                        elif i == fin and j != self.chemin[-2]:
                            min_val = D[i, j]
                some += min_val

            # Cas 3 : i non dans le chemin : A->B->C->D     Z
            else:
                sorted_indices = np.argsort(D[i])
                # sorted_indices[0] est i (dist 0), on prend [1] et [2]
                some += D[i, sorted_indices[1]] + D[i, sorted_indices[2]]

        borne = some / 2.0
        return borne

    def __lt__(self, other):
        return self.borne < other.borne

class Tas:
    def __init__(self):
        self.tas = []

    def __versLeHaut(self, i):
        """
        Fait remonter un élément dans le tas pour respecter la propriété de tas min.
        Args:
            i (int): Indice de l'élément à faire remonter.
        """
        # Remonter tant que l'élément a une priorité inférieure à son parent
        while i > 0 and self.priorite(i) < self.priorite((i - 1) // 2):
            # Échanger avec le parent
            self.echanger(i, (i - 1) // 2)
            # Mettre à jour l'indice pour continuer à remonter
            i = (i - 1) // 2

    def __versLeBas(self, i):
        """
        Fait descendre un élément dans le tas pour respecter la propriété de tas min.
        Args:
            i (int): Indice de l'élément à faire descendre.
        """
        # Indice du fils gauche
        s = 2 * i + 1
        # Descendre tant que l'élément a une priorité supérieure à l'un de ses enfants
        while s < len(self.tas):
            # Trouver l'enfant avec la plus petite priorité en comparant les deux fils et si c'est le droit
            if s + 1 < len(self.tas) and self.priorite(s + 1) < self.priorite(s):
                # Prendre le fils droit
                s += 1
            # Si l'élément courant a une priorité supérieure à son enfant
            if self.priorite(i) > self.priorite(s):
                # echanger et continuer à descendre
                self.echanger(i, s)
                # Mettre à jour l'indice courant de l'elément à descendre
                i = s
                # Mettre à jour l'indice avec le fils gauche
                s = 2 * i + 1
            # Sinon, la propriété de tas est respectée
            else:
                break

    def insere(self, elem):
        """
        Insère un nouvel élément dans le tas et rétablit la propriété de tas min.

        Args:
            elem: L'élément à insérer.
        """
        self.tas.append(elem)
        self.__versLeHaut(len(self.tas) - 1)

    def extraire_min(self):
        """
        Extrait et retourne l'élément de priorité minimale (la racine du tas).
        Réorganise le tas après l'extraction.

        Returns:
            L'élément minimal, ou None si le tas est vide.
        """
        if len(self.tas) == 0:
            return None
        # Extraire le minimum (racine)
        min_noeud = self.tas[0]
        # Remplacer la racine par le dernier élément
        self.tas[0] = self.tas[-1]
        self.tas.pop()
        # Réajuster le tas
        if len(self.tas) > 0:
            self.__versLeBas(0)
        return min_noeud
    
    def priorite(self, i):
        return self.tas[i].borne

    def echanger(self, i, j):
        self.tas[i], self.tas[j] = self.tas[j], self.tas[i]

def hds(D):
    """
    construire un cycle hamiltonien en utilisant la méthode de Branch and Bound (HDS).
    Args:
        D (np.ndarray): Matrice des distances.
    Returns:
        tuple: (c, l) cycle hamiltonien (liste d'indices), longueur du cycle
    """
    c = []
    l = float('inf')
    n = len(D)

    if n < 3:
        if n == 0:
            return [], 0
        if n == 1:
            return [0, 0], 0
        if n == 2:
            return [0, 1, 0], D[0, 1] * 2

    tas = Tas()
    # Initialisation du tas avec le noeud racine
    noeud_racine = Noeud([0], 0.0, D)
    tas.insere(noeud_racine)

    while True:
        # Extraire le noeud avec la plus petite borne
        noeud_courant = tas.extraire_min()
        if noeud_courant is None:
            break

        # si la borne théorique est supérieure à la meilleure solution trouvée, on ignore ce noeud
        if noeud_courant.borne >= l:
            continue

        # Si le chemin est complet
        if len(noeud_courant.chemin) == n:
            # Ajouter le coût de retour au point de départ
            cout_total = noeud_courant.cout_actuel + D[noeud_courant.dernier, noeud_courant.chemin[0]]
            # Si ce coût est inférieur à la meilleure solution trouvée
            if cout_total < l:
                l = cout_total
                c = noeud_courant.chemin + [noeud_courant.chemin[0]]
        else:
            # Générer les successeurs possibles
            for i in range(n):
                if i not in noeud_courant.chemin:
                    nouveau_chemin = noeud_courant.chemin + [i]
                    nouveau_cout = noeud_courant.cout_actuel + D[noeud_courant.dernier, i]
                    nouveau_noeud = Noeud(nouveau_chemin, nouveau_cout, D)
                    # Insérer le nouveau noeud dans le tas
                    tas.insere(nouveau_noeud)
                    
    return c, l
